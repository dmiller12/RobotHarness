# Robot Agentic Harness

<video src="https://github.com/user-attachments/assets/4bfcb79f-58e4-4628-bdad-2b8d6090b6e9" controls width="100%"></video>

This repository contains a Rust-based robot harness designed to manage a Vision-Language-Action (VLA) model for controlling a manipulator.
The harness generates a plan from a high level goal, and continuously evaluates plan progress.
